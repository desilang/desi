
# 03 · Functions

Multi-line and single-line forms:

```desi
def inc(x: int) -> int:
  return x + 1

def inc1(x: int) -> int: return x + 1
```

Multiple parameters and returns are annotated:

```desi
def add(a: int, b: int) -> int:
  a + b
```

Call syntax is standard:

```desi
let y = inc(41)
```
