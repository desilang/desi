# 01 · Hello, World

Desi uses indentation-based blocks and a trailing `:` after headers. Single-line forms are also supported.

```desi
def main() -> int:
  print("hello, world")
  0
```

**Key points**

* `def main() -> int:` declares a function returning `int`.
* `print` joins multiple arguments with spaces and writes a newline.
* Ending with `0` is an expression statement; you can also `return 0`.
