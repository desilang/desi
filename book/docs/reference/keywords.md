# Keywords

Reserved keywords in Desi.

---

## Declaration Keywords

| Keyword | Description |
|---------|-------------|
| `let` | Immutable variable |
| `var` | Mutable variable |
| `def` | Function definition |
| `class` | Class definition |
| `struct` | Struct definition |
| `enum` | Enum definition |
| `pub` | Public visibility |
| `mut` | Mutable field |

---

## Control Flow Keywords

| Keyword | Description |
|---------|-------------|
| `if` | Conditional |
| `elif` | Else if |
| `else` | Else branch |
| `for` | For loop |
| `while` | While loop |
| `match` | Pattern matching |
| `case` | Match case |
| `break` | Break loop |
| `continue` | Continue loop |
| `return` | Return value |
| `pass` | No-op statement |

---

## Boolean Keywords

| Keyword | Description |
|---------|-------------|
| `true` | Boolean true |
| `false` | Boolean false |
| `and` | Logical AND |
| `or` | Logical OR |
| `not` | Logical NOT |

---

| Keyword | Description |
|---------|-------------|
| `in` | Membership/iteration |
| `is` | Type check |
| `self` | Instance reference |
| `cls` | Class reference |
| `using` | Resource management |
| `import` | Module import |
| `from` | Import from |
| `as` | Alias |
| `async` | Async function |
| `await` | Await async |
